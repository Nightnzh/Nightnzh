## 👨‍💻 關於我

我負責開發與維護**自助點餐機與店員 POS 收銀機**的核心 Android 產品線，服務全台連鎖餐飲品牌。五年下來，我學到最多的來自一個一般 App 沒有的限制：**軟體必須是對的，因為一個 bug 代表週六晚上有顧客的現金卡在機器裡。**

- 💳 **付款架構** — 主導付款模組從舊有 Java MVP 漸進遷移至 Kotlin MVVM，降低耦合、讓多階段流程真的可被測試
- 🏧 **支付與現金硬體** — 整合刷卡機、行動支付與抵用券方案，並串接紙鈔機、硬幣機，含夾在中間的多階段找零與退券路徑
- 🚀 **大規模現代化** — 主導多模組 codebase 的 AGP 8 + Kotlin 2.0 升級，建置 Jetpack Compose 設計系統與可重用元件庫
- 🧪 **測試文化** — 在幾乎沒有覆蓋率的專案導入 MockK 與 Robolectric，聚焦付款／會員點數／優惠券邏輯，並接上 GitLab CI
- 🔌 **周邊與區網** — USB／Serial／TCP 整合發票與標籤印表機、條碼掃描器，並維護區網設備探索與離線容錯背景同步
- 🤖 **正在做的** — 把自己的開發流程工具化：可重用的 agent skills、review 自動化、專案專屬判斷準則

> 同一份 codebase 要出貨到多條產品線、橫跨一整批 Android 版本與周邊韌體都不同的機型。所以我 review 時花最多時間在兩件真的會在現場出事的事上：**對已出貨機台的向下相容，以及共用程式碼悄悄跨產品線洩漏。**
